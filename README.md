# TuGiro Bolivia 🔄

Sitio web oficial de **TuGiro Bolivia** — envío y recepción de dinero en BOB, USD y USDT.

## Estructura

```
tugiro/
├── index.html              ← Página "Próximamente" (activa)
├── pages/
│   ├── inicio.html         ← Home principal (en construcción)
│   ├── servicios.html      ← Servicios / tipos de giro
│   └── contacto.html       ← Contacto y ubicación
├── components/
│   ├── navbar.html         ← Barra de navegación
│   └── footer.html         ← Pie de página
└── assets/
    ├── css/
    │   ├── variables.css   ← Tokens de diseño (colores, fuentes, espaciado)
    │   └── style.css       ← Estilos globales
    ├── js/
    │   └── main.js         ← JS principal
    ├── images/             ← Logo, imágenes, íconos
    └── fonts/              ← Fuentes locales (si aplica)
```
